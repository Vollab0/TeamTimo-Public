# Le Médecin

![[PNJ_Medecin.jpg|220]]

## Rôles
- **Soigner** les joueurs.
- **Réanimer** un joueur mort. Si les autres joueurs ont réussi à **ramener son corps**, la réanimation est **gratuite (ou peu chère)**.

## S'il est enlevé
- Les joueurs ne peuvent se soigner **qu'avec des baies**.
- Ils peuvent utiliser un **kit de réanimation** pour réanimer un autre joueur.
