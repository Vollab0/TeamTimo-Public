# Le Banquier

![[PNJ_Banquier.jpg|220]]

## Rôle
- **Stocke les pièces** de tout le monde : c'est la **banque commune** de l'équipe (l'or porté, lui, est individuel — décidé le 2026-11-08).
- Prend **une pièce par jour** d'intérêt.

## S'il est enlevé
- Il **lâche les pièces** : les joueurs doivent se les séparer.
